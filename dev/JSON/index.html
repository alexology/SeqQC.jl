JSON report — schema seqqc-result 1.0.0

report(result, "sample.json")                         # or write_json(path_or_io, result)
s = to_json(result; fastqc = true)                    # string, with FastQC-compatible tables
to_json(result; omit = ())                            # everything, raw histograms included

The document is produced by a small built-in writer (no JSON dependency) and is checked against an independent parser (JSON3.jl) in the tests. Files are written to a temporary file in the target directory and then renamed.

Versioning

schema_version follows semantic versioning: adding fields is a minor change; renaming or removing a field, or changing its type or meaning, is a major change. Consumers should check schema and the major version.

Matrices in the default metrics: quality_vs_length.counts (rows = length bins, columns = quality bins), per_position.base_counts (rows = A, C, G, T, U, N, other; columns = positions), per_position.quality_quantiles (rows = 10, 25, 50, 75, 90%).

Size

By default raw_quality_histograms (94 numbers per read position, needed only to recompute FastQC tables) is omitted. Everything else is bounded by the number of distinct read lengths and of read positions. Measured on 2026-11-13 (minified output):

Aggregate document — schema seqqc-aggregate 1.0.0

Written by report(set, "x.json") / to_json(set) for a SampleSet (docs/src/MULTISAMPLE.md): schema, schema_version, settings (low_reads_fraction, software, sample_schema_versions), samples, sources (input path of each sample), table (one array per column, null for missing values; fastqc_flags as objects or null), series (the plotted distributions on common bins: length with edges, scale, fraction, yield; read_quality, base_quality, gc with their bins and fraction matrices, samples × bins; position_quality with edges, mean_quality (samples × position bins, Phred; null where not shown), min_bases, min_fraction) and warnings.

Reading reports back

read_json(path) parses any JSON document (strict RFC 8259, built in): objects become Dict{String,Any}, numeric arrays Vector{Int} or Vector{Float64}, other arrays Vector{Any}, null becomes nothing. Integers outside the Int64 range are read as Float64.
